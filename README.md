# 🔱 Divine Dots – Maa Kali

**Divine Dots** is a creative WebGL-based visualization project that transforms an image of Maa Kali into thousands of glowing, interactive particles.

Built with JavaScript and Three.js, the project uses image processing, pixel sampling, RGB color extraction, and particle physics to reconstruct the visual appearance of Maa Kali through a dynamic 3D particle system.

### ✨ Key Features

- **Image-to-Particle Conversion:** Transforms image pixels into 3D particle coordinates.
- **Dual Formations:** Supports separate face and full-idol particle formations.
- **RGB Color Mapping:** Preserves original image colours.
- **Particle Physics:** Uses attraction and damping for smooth formation transitions.
- **Interactive Visualization:** Switch between formations using keyboard controls.
- **WebGL Rendering:** GPU-accelerated rendering with Three.js.

### 🛠️ Tech Stack

- JavaScript (ES6+)
- Three.js
- HTML5
- CSS3
- Canvas API
- WebGL

To combine programming, mathematics, computer graphics, and creativity to create a digital representation of Maa Kali through thousands of luminous particles.
